   - **Status:** **FULLY AVAILABLE & VERIFIED**
   - **Checkpoint:** `data/models/rampnet.safetensors` (360 MB, SHA-256: `f2119e3becb0b551fa1470f7b7ba85b82122a3f73a6ed2a85609dd57617866b5`).

   - **Status:** **FULLY AVAILABLE & VERIFIED**

In production, strict mode correctly returns `UNAVAILABLE`. For offline testing, an explicit `allow_fallback=True` flag enables calibrated baseline heuristics clearly labeled as `heuristic_fallback`.

## 3. External API Credentials & Provider Access

1. **Mapillary API v4:**
   - Requires `MAPILLARY_CLIENT_TOKEN` environment variable.
   - Without an authorized client token, `MapillaryConnector` reports `status = "unauthenticated"`. It does **NOT** generate synthetic items with fake URLs.
   - Acquisition of live imagery from Mapillary is currently **BLOCKED** pending client token configuration.

2. **KartaView Public API:**
   - Requires `KARTAVIEW_API_KEY` for high-throughput querying.
   - Without a key, `KartaViewConnector` reports `status = "unauthenticated"`.

## 4. Hardware Constraints (RTX 3050 4GB VRAM)

1. **Memory Budget:**
   - The deployment environment provides 4,096 MiB VRAM.
   - Concurrent loading of RampNet (1.2 GB), HRNet CitySurfaces (2.2 GB), and YOLOv8 simultaneously exceeds available VRAM and triggers CUDA OOM errors.
2. **Mitigation:**
   - AccessGuard defaults to `HYBRID_MODE = "RESOURCE_CONSTRAINED"`.
   - Adapters are loaded sequentially, executed, and unloaded with `gc.collect()` and `torch.cuda.empty_cache()` between stages.

## 5. Unmeasured Metrics and Synthetic Benchmarks

1. **Geospatial and Temporal Metrics:**
   - PostGIS segment association accuracy and temporal deduplication efficiency cannot be honestly scored using static single-frame test images.
   - RealityEngine reports these as `status: "NOT_MEASURED"` until real multi-frame video sequences with ground-truth PostGIS GPS segment pairs are ingested.

2. **Indian Streetscapes Benchmark Dataset:**
   - The 25 scenes in `data/benchmarks/indian_streetscapes` generated by `scripts/generate_indian_benchmark.py` are **procedural synthetic geometric drawings**, not real field photography.
   - They are explicitly labeled as `synthetic_procedural_validation_suite` for unit sanity testing.
